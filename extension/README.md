# PromptHub 浏览器扩展

用于从网页识别并收藏 AI 图像提示词。完整运行规则见 [../OPERATING_RULES.md](../OPERATING_RULES.md)。

## 当前同步方式

1. 扩展先将识别完成的内容放入短暂本机队列，避免同时收藏时相互覆盖。
2. 队列立即提交一个小型入站批次到 GitHub 的 `data/inbox/*.json`，不再由浏览器直接读写整份 `data/collections.json`。
3. 只有 GitHub 确认入站批次创建成功后，扩展才显示“已提交 GitHub 主站队列，等待自动合并或去重”。失败项目保留在队列中重试。
4. 仓库端 `Merge Extension Inbox` 工作流会读取最新主站数据，将入站批次合并进 `data/collections.json`，并删除已处理的入站文件。
5. GitHub 主站成功至少 30 分钟后，GitHub Action 自动将其发布到国内站；扩展不直接操作国内站，正常发布无需用户操作。

本机存储不是收藏数据源，仅保存失败重试队列和用户本机的 GitHub Token。跨设备浏览时，应以主站数据为准。

## 安装

1. 打开 `chrome://extensions/`（Edge 使用 `edge://extensions/`）。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本 `extension` 文件夹，或从 PromptHub 的导入页面下载当前扩展包。
5. 在扩展设置中配置拥有仓库 Contents 读写权限的 GitHub Token。

## 使用

- 在网页选中文本后使用右键收藏，或打开扩展扫描当前页面；检测到多条时可点“一键收藏”，一次加入全部合格候选。
- 扩展会过滤短片段、界面文案、重复来源和没有结果媒体的候选项。
- 识别成功后，会显示 GitHub 主站队列的提交结果；“待同步”仅表示入站提交失败后等待重试的项目数。
- X 帖子会保存具体状态页链接，不会把书签列表页当作来源。

## 何时需要更新扩展

仅当扩展本身的识别、权限、收藏交互、同步协议或扩展内状态文案变更时，才需要安装新的扩展包。主站页面、SEO、数据或国内站发布变更不需要更新扩展。
