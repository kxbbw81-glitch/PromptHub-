# PromptHub

PromptHub 是一个面向 AI 图像与视频创作的提示词收藏网站，用于整理、检索、复制和管理高质量 Prompt。项目重点是把分散在网页、社交平台和公开案例中的优秀提示词，沉淀为结构化、可追溯、可持续更新的提示词库。

主站：

```text
https://kxbbw81-glitch.github.io/PromptHub-/
```

国内站：

```text
https://prompthub.kxbbw81.workers.dev/
```

## 项目定位

PromptHub 不是图像生成器本身，而是一个提示词资产库。

它主要解决几个问题：

- 好提示词分散在不同平台，难以长期保存。
- 手动复制整理效率低，容易丢图片、丢来源、丢标题。
- 提示词数量变多后，需要分类、搜索、筛选和详情页。
- 不同设备之间需要统一数据源，而不是只存在某台电脑本地。
- 国内访问环境需要更稳定的展示站点。

## 核心功能

- 提示词收藏与管理
- 图像 / 视频提示词详情页
- 一键复制完整 Prompt
- 首页瀑布流图片墙
- 探索页分类筛选
- 电商视觉分类与二级用途
- 收藏数据跨设备同步
- 浏览器扩展辅助收集
- 主站与国内站双站点展示
- 每日内容质量整理
- 独立提示词页面，利于长期沉淀和 SEO

## 内容类型

PromptHub 当前重点整理以下方向：

- 人像摄影
- 时尚视觉
- 电商视觉
- 产品主图
- 广告海报
- 品牌视觉
- 建筑空间
- 场景与氛围
- 插画与艺术
- 文生视频提示词

其中“电商视觉”是重点分类，适合沉淀产品拍摄、主图、种草图、详情页、广告海报、UGC 口碑、模特展示等商业视觉 Prompt。

## 网站结构

常见页面：

```text
首页
探索提示词
导入提示词
我的收藏
免责声明
提示词详情页
```

提示词详情页通常包含：

- 标题
- 结果图或视频封面
- 完整提示词
- 分类
- 标签
- 模型信息
- 宽高比
- 来源链接
- 收藏时间

## 数据同步方式

PromptHub 使用 GitHub 仓库作为主数据源。收藏成功后，数据先同步到 GitHub 主站；国内站会在服务端规则满足后延迟更新。

简化流程：

```text
收藏提示词 -> 写入 GitHub 主站 -> 主站确认 -> 国内站延迟发布
```

这样做的好处：

- 多台电脑看到的是同一份收藏数据。
- 不依赖浏览器本地存储作为长期数据源。
- 主站和国内站可以分别适配不同网络环境。
- 数据可版本化，方便回溯。

## 浏览器扩展

仓库包含 PromptHub 浏览器扩展，用于辅助从网页中识别并收藏提示词。

扩展支持：

- 扫描当前页面
- 单条收藏
- 一键收藏多条识别结果
- 收藏队列
- GitHub 主站写入确认
- 失败后保留队列等待重试

当前扩展包位于仓库根目录，文件名格式：

```text
PromptHub-Extension-vX.Y.Z.zip
```

也可以在网站的“导入提示词”页面下载当前版本。

本项目是静态站点，可以使用任意静态服务器打开。

示例：

```powershell
python -m http.server 8787
```

```text

```

## 发布说明

一般页面或数据更新，推送到 `main` 后由 GitHub Pages 展示。

扩展代码更新时，需要重新打包扩展，并同步更新网站下载入口。

国内站由既有发布流程处理，不建议在浏览器端直接写入国内站。

## 安全说明

- 不要提交 GitHub Token、Cookie、登录凭据或本机缓存。
- 浏览器扩展的 Token 只应保存在本机。
- 收藏内容用于商业项目时，需要自行确认原始来源、模型条款、图片权利和适用授权。
- 外部图片或来源链接可能失效，站点不保证第三方资源永久可用。
